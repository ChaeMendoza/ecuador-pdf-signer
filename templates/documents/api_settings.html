Guía de Integración Rápida

1. Cabecera

Añade el siguiente Header HTTP a todas tus peticiones:

Authorization: Token TU_API_KEY
2. Firma Individual

Envía un POST tipo multipart/form-data a:

POST /api/v1/sign/individual/

Ejemplo CURL:

curl -X POST \
  -H "Authorization: Token " \
  -F "pdf_file=@certificado.pdf" \
  -F "p12_file=@firma.p12" \
  -F "password=ClaveFirma123" \
  -F "profile_id=1" \
  http://localhost:8000/api/v1/sign/individual/ \
  --output firmado.pdf
3. Firma Masiva (ZIP)

Envía múltiples archivos PDF en el campo documents:

POST /api/v1/sign/batch/

Ejemplo CURL:

curl -X POST \
  -H "Authorization: Token " \
  -F "documents=@certificado1.pdf" \
  -F "documents=@certificado2.pdf" \
  -F "p12_file=@firma.p12" \
  -F "password=ClaveFirma123" \
  -F "profile_id=1" \
  http://localhost:8000/api/v1/sign/batch/ \
  --output firmados.zip

Tip de Posicionamiento:

El sistema usa puntos PDF (1 pulgada = 72 puntos). Un certificado A4 estándar mide 595 x 842 puntos.
